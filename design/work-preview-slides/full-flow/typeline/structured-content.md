# typeline

## Overview
A text-free portfolio preview image for typeline. The image should communicate the project domain through color, structure, and visual metaphor.

## Learning Objectives
The viewer will understand:
1. The project's visual mood and domain.
2. The key system metaphor behind the project.
3. That this is a polished project card image, not a screenshot.

---

## Section 1: Core metaphor

**Key Concept**: minimal dark typing-game surface with precise cyan interaction feedback; no literal UI text or words in the art.

**Content**:
- "A full typing game focused on rhythm, flow, shared room seeds, retry loops, and input feedback."

**Visual Element**:
- Type: text-free title-slide illustration
- Subject: abstract typing rhythm: glowing cursor trail, keypress pulse arcs, speed/accuracy energy forms, shared-room orbit, dark negative space
- Treatment: Baoyu-quality generated infographic art; no readable text, no UI labels, no code snippets, no logos.

**Text Labels**:
- None. The generated image must contain no words, no letters, no numbers, and no fake glyph text.

## Design Instructions

### Style Preferences
- Full Baoyu infographic/title-slide workflow.
- Generated image model output only; no SVG/HTML text render shortcuts.
- No words, no letters, no numerals, no logos, no screenshots.
- Landscape 16:9.
- Palette: near-black #0d0d0d, cyan #00e5ef, muted gray #6e6e73, soft white #e9e9e9

### Layout Preferences
- One central hero visual metaphor.
- Balanced supporting symbols.
- Strong silhouette and mobile readability.
