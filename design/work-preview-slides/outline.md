# Work project preview slides

Baoyu-style assistive preview graphics for deployed WORK cards. These are not title slides; the card title lives in UI text outside the image. Slides should read as product-surface previews / conceptual UI schematics.

## Shared visual system

- landscape 16:9 card covers
- warm portfolio paper background
- crisp flat vector / technical schematic feel
- minimal or no text inside the image to avoid garbled model lettering
- use each project's accent as the dominant color
- no author name, no byline, no fake app title block
